# Security reporting

Manzil handles account and optional location data. Please report security issues privately before publishing reproduction details.

- Use GitHub's **Security → Report a vulnerability** when private vulnerability reporting is enabled for this repository.
- If that option is unavailable, use an existing private contact channel with a repository maintainer. If you have no private channel, a public issue may request one without describing the vulnerability or including exploit data. No dedicated security email or response-time commitment is currently published.
- Do not include passwords, API keys, tokens, private source evidence, account exports or precise GPS traces in public issues, discussions or screenshots. Use redacted or synthetic examples.
- Include the affected commit/release, deployment mode and a minimal reproducible example. Report tests against your own local instance; do not probe other users' data on the hosted service.

This is an MVP with a separately operated hosted deployment. A feature-branch fix does not establish that the hosted service has received it. Maintainers should coordinate the affected code, deployment and any necessary credential rotation privately.
